1 Description

[hide]

RC-Astro CLI Wrapper provides a PixInsight graphical interface for the stand-alone BlurXTerminator, StarXTerminator, and NoiseXTerminator command-line tools. It can process the active PixInsight view or image files selected manually. The documentation button beside the Preferences button opens this bundled compiler-generated PIDoc page.

1.1 Requirements

PixInsight 1.9.4 or newer with the V8 JavaScript runtime is required. RC-Astro CLI version 1.0.0 or newer is required. This release has been tested with RC-Astro CLI version 1.1.0.

1.2 Startup checks

At startup, the script locates the configured RC-Astro executable and reads its machine-readable catalog with rc-astro –json. Versions older than 1.0.0 are rejected. Versions newer than 1.1.0 generate a warning because they were not available when this wrapper was tested. When the check succeeds, the main status area displays Ready together with the installed CLI version and executable path.

1.3 Processing modes

  • Active PixInsight view saves a temporary XISF copy of the selected view, runs RC-Astro, and opens the result as a new image.
  • Manual file processes an input file and writes to the selected output path.

The triangular New Instance button at the lower left creates a standard PixInsight process icon containing the current RC-Astro processing settings. Drag or click the icon onto a view to reuse those settings. Active-view instances obtain their image from the target or active view; manual-file instances also retain their input, output, and log paths. Machine-specific executable and temporary-directory preferences, detected CLI status, progress, and other transient run-time state are deliberately excluded. Configure machine-specific paths with the Preferences button on each computer.

When a result is opened, the wrapper copies the exact screen transfer function (STF) of the input view. A nonidentity STF is retained for the usual linear-image workflow, while an identity STF remains identity for an already stretched nonlinear image, avoiding an unintended second stretch. This changes display only and never modifies output pixels. In manual-file mode the STF can be copied only when the selected input file is already open in PixInsight; otherwise the result opens with its default identity STF. The same rule is applied to an optional StarXTerminator stars-only output.

1.4 BlurXTerminator

Automatic nonstellar PSF is the normal mode. BlurXTerminator estimates the PSF from stars and can correct optical aberrations in nonstellar features.

For starless, lunar, or planetary images, disable automatic nonstellar PSF and set the nonstellar diameter to the expected stellar FWHM in pixels. Manual mode assumes a round PSF and cannot correct optical aberrations.

This wrapper uses the RC-Astro 1.0.0 and later parameters –auto-nonstellar-psf and –nonstellar-diameter. The obsolete radius parameters are not used.

1.5 StarXTerminator

The StarXTerminator panel provides optional stars-image output and unscreened-stars controls in addition to the common RC-Astro options.

1.6 NoiseXTerminator

The NoiseXTerminator panel provides controls for luminance and color denoising, frequency scale, and iterations. The newer ML3 model produces the same result with improved execution speed on Windows and Linux. The macOS NoiseXTerminator ML3 model was not updated with this optimization.

1.7 Progress and cancellation

RC-Astro output is monitored while processing. A job is stopped if the process produces no new output for 55 minutes. The total processing time is otherwise not limited. Closing the dialog during processing requests cancellation. Completion and failure details are shown in the main status area and written to the PixInsight console; successful completion does not display a modal popup.

1.8 Troubleshooting

  • CLI not found: Open Preferences and select the installed rc-astro executable.
  • Version check failed: Run rc-astro –json in a terminal and verify that it returns a cliVersion.
  • Exit code 77: The selected RC-Astro product is not licensed on this computer.
  • Missing output: Inspect the full log and verify that the output directory is writable.
